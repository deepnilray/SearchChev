# SearchChev paper: master checklist (written 28 Nov 2026, 02:00 IST)

Every scheduled session works from this file. An item is ticked only when its result is verified at the
destination (file regenerated from data, number re-computed by script, page reloaded), with the commit hash.
Nothing goes public (preprint, Zenodo, VSX, LinkedIn, journal) while any item it depends on is open.

## Standing rules (apply to every item)
- R1 Freshness sweep before any public claim: search arXiv, ADS, Zenodo, GitHub, CDS/VizieR, IRSA and team pages for
  anything on the same stars, the same survey or the same question released in the last 6 months, not only
  catalogues already on our list. Record the query, date and result in paper/FRESHNESS.md.
- R2 Code-vs-text audit: every method sentence is checked against the code line that implements it.
- R3 Every number in the text is a macro generated by paper/v2/make_numbers.py from archived data.
- R4 Independent hostile review by a fresh agent that has not seen the drafting, before every public version.
- R5 State limits openly; never upgrade a claim beyond what the checks support.
